Settings

Paste a GitHub fine-grained personal access token with Contents: Read and write to let this page load and save your tasks. One token is used for every repo you can access — scope it to whichever you need:

  • sandstormveg/tasks (public) for the Active/History/Assistance tabs to work at all.
  • sandstormveg/tasks-data (private) too, if you also want private tasks to load and be editable.

To give someone edit access to only the public tasks — never the private ones — create a separate fine-grained token scoped only to sandstormveg/tasks and have them paste that into their own browser's Settings here. They don't need your token at all. Calls to the private repo will just fail for them and those tasks won't show — no code change needed, it's purely which repo(s) the token itself can see.

Your token is stored only in your browser (localStorage), never sent anywhere except GitHub's API.
