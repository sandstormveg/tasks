Tasks Sync privacy policy

Last updated: 7 November 2026

What it accesses

Tasks Sync asks Google for read-only access to the signed-in user's Google Tasks (the tasks.readonly scope). It reads task titles, due dates, notes and whether each task is completed.

How the data is used

The data is used for one purpose only: copying the owner's tasks into the owner's personal task tracker. Nothing is used for advertising, profiling or any other purpose.

Where it is stored

The sign-in token is kept only on the owner's own computer. Copied tasks are stored in the owner's own task tracker. The data is not sold, and it is not shared with anyone else.

Who can use it

Tasks Sync is a personal tool used only by its owner. No other users' data is collected.

Removing access

Access can be revoked at any time from your Google Account: Security, then Third-party apps & services, then Tasks Sync.
