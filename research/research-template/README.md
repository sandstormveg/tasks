# Research

Your private reading library: things you mean to read, are reading and have read, with your tags,
why you saved each one, what you expected, what surprised you, notes and exact quotes. Written by
the Research app (the § tab in Tasks); one Markdown file per source under `sources/YYYY/MM/`.

| Path | What | Who writes it |
| --- | --- | --- |
| `sources/` | One file per thing you saved | You, in the app (Claude can add sources and change status/⭐/tags) |
| `tools/research.mjs` | Query tool for Claude sessions | Generated by the app — don't edit |
| `CLAUDE.md`, `.claude/skills/research/` | How Claude should work with this folder | Generated by the app |

A source file looks like this:

```markdown
---
id: s-20261101-0930-k7q2
type: source
kind: paper
title: "Risks of astronomical future suffering"
url: https://…
status: read          # inbox | to-read | reading | read | dropped
favourite: true
tags: [s-risk, ethics]
added: 2026-11-01T09:30:00+07:00
why: "Foundational for the reading group"
expect: "Argues s-risks outweigh extinction risks"
surprised: "How much rests on the tractability argument"
quotes:
  - text: "…"
    where: "§3"
visibility: private
---
My notes, in Markdown.
```
